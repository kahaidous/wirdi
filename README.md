# Wirdi

Wirdi is a Flutter mobile app for tracking daily **wird** ("mouraja3a") of Qur'an with a teacher. The app helps teachers and students stay aligned on daily review goals, progress, and accountability through structured groups and tasks.

## Core Concepts

- **Users** belong to a **group** that has a dedicated **teacher**.
- **Teachers** can create multiple groups to organize students.
- **Teachers** define a **daily task** (wird/mouraja3a) for each group.

## Planned Features

- Group-based student enrollment and teacher assignment.
- Daily task creation and updates by teachers.
- Student progress tracking and history of completed wird.
- Notifications and reminders for daily tasks.

## Getting Started

1. Install Flutter (SDK 3.3+).
2. Fetch dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```

## Repository Structure

- `lib/` — Flutter application source code.
- `pubspec.yaml` — Flutter project configuration and dependencies.
